# CodeAlpha_Basic_Chatbot
A simple rule-based chatbot built in Python as part of the CodeAlpha Python Programming Internship. The chatbot takes user input, matches it against predefined messages (hello, how are you, bye), and responds accordingly using functions, loops, and conditional statements. Built using core Python concepts — no external libraries required.
## Features
- Rule-based response matching
- Case-insensitive input handling
- Clean exit on "bye"

## Concepts Used
- Functions
- Loops (while)
- Conditional statements (if-elif-else)
- String methods (.lower())

## How to Run
python chatbot.py
